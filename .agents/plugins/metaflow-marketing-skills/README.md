# Marketing skills

Agent skill packs for **paid search**, **paid social**, **cross-channel paid media**, **SEO / AEO**, and **AI visibility** (GEO / LLM prompt libraries). Markdown only.

## Contents

| Pillar | Slugs (examples) |
|--------|-------------------|
| Paid search | `paid-search-ads-playbook`, `google-ads-account-audit`, `google-ads-campaign-builder`, … |
| Paid social | `meta-ads-playbook`, `meta-ads-campaign-builder`, `meta-ads-creative-engine`, … |
| Paid media (cross-channel) | `ad-spend-allocator`, `campaign-analyzer`, `paid-media-reporter` |
| SEO / AEO | `ai-search-visibility-aeo-geo-llmo`, `seo-aeo-content-strategy`, `technical-seo-ai-crawler-audit`, `bofu-seo-aeo-strategy`, … |
| Visibility | `prompt-picker` |

## Claude Code

Install the plugin from `.claude-plugin/marketplace.json` (see `metadata.repository` for this repo’s URL).

## Cursor

Copy or symlink skill folders under `.cursor/skills/` if you use Cursor’s skills layout.
