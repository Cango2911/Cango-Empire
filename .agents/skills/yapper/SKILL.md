# Yapper — Medical Interview Simulation Game

Free patient interview practice game for healthcare students (nursing, PA, medical).
No API key needed — everything runs locally via an embedded 29 MB SLM.

## Setup

### Requirements

- Java 21+ (OpenJDK recommended)
- ~300 MB free disk space
- No internet connection needed after download

Check your Java version:
```bash
java -version
# Should show: openjdk version "21.x.x" or higher
```

Install Java 21 if needed:
```bash
# macOS (Homebrew)
brew install openjdk@21

# Ubuntu/Debian
sudo apt install openjdk-21-jdk

# Windows: download from https://adoptium.net
```

### Download and Run

```bash
# Download the JAR (~80 MB — includes embedded LLM model)
curl -L -o yapper.jar https://github.com/02developer/yapper/raw/main/yapper.jar

# Run
java -jar yapper.jar
```

Or download `yapper.jar` directly from: https://github.com/02developer/yapper

## Gameplay

### What it is

A 16-bit GBA-style medical interview simulation. You play as a doctor conducting a patient history interview, with the AI responding as the patient in real time.

Visual style inspired by: The Legend of Zelda: The Minish Cap, Pokémon Leaf Green, The Invincible Iron Man.

### The Simulated Patient — Alex Morgan

| Field | Details |
|-------|---------|
| Name | Alex Morgan |
| Age | 34 (DOB: June 15, 1990) |
| Sex | Randomized per session (male/female) for sex-specific history practice |
| Occupation | Graphic designer |
| Relationship status | Married (met partner in high school) |
| Chief complaint | 6-month history of heartburn, rated 7/10 in severity |
| Aggravating factors | Stress, large meals; sometimes accompanied by nausea or sour taste |
| PMH | Wisdom teeth removal (2013); no hospitalizations |
| Medications | None significant |

### Interview Format

Based on the NEJM Resident360 medical interview framework. You can ask about:
- Chief complaint and HPI (history of present illness)
- Onset, duration, severity, quality, radiation, timing, modifying factors
- Associated symptoms (nausea, vomiting, regurgitation, dysphagia)
- Past medical and surgical history
- Medications and allergies
- Family history
- Social history (occupation, relationship, habits)
- Review of systems

### Timer

- Set your own interview time limit at the start
- When the countdown ends, you can choose to continue or end the interview

## How the AI Works

The patient responses are generated by a local small language model (SLM):
- **Architecture:** Llama2-based Java inference engine (Llama2App.jar)
- **Model size:** 29 MB (model.bin) + 69 KB (tokenizer.bin) — embedded in yapper.jar
- **Speed:** ~112–120 tokens/sec on an 8th-gen i5 with 8 GB RAM
- **Execution:** `ProcessBuilder` launches `java -jar Llama2App.jar` as a local subprocess
- **Privacy:** No data leaves your machine — fully offline

## Troubleshooting

**"java: command not found"**
Install Java 21: `brew install openjdk@21` (macOS) or `sudo apt install openjdk-21-jdk` (Linux)

**App opens but AI responses are slow**
Normal on low-end hardware. The SLM runs at ~112–120 tok/s on mid-range i5. More RAM helps.

**JAR won't open on macOS (Gatekeeper)**
```bash
xattr -d com.apple.quarantine yapper.jar
java -jar yapper.jar
```

**Blank screen on startup**
Ensure Java 21+. Java 17 may not support `--enable-preview` + `jdk.incubator.vector` flags used by the LLM inference engine.

## Legacy Versions (macOS only)

The `yapper-legacy/` folder contains older v2.0 macOS `.app` bundles in three languages:
- `interview_game-2.0-mac.zip` — English
- `german_interview_game-2.0-mac.zip` — German
- `spanish_interview_game-2.0-mac.zip` — Spanish

Use the `script.sh` helper to make the run script executable:
```bash
# After extracting the .zip
./script.sh
```

These are macOS-only and superseded by `yapper.jar` which is cross-platform.
