# VoltAgent AI Agent Examples

Ausführbare Beispiele für das VoltAgent TypeScript-Framework.

## Starten

```bash
npm create voltagent@latest -- --example <example-name>
```

## Beispiel-Kategorien

### RAG & Retrieval
- Pinecone Vector Search
- Chroma, Qdrant, Postgres Integration
- Document Ingestion und Chunking

### Typed Tools
- Zod-validierte Tools
- MCP Server Integration
- Externe API-Anbindung

### Memory Systems
- Working Memory
- Persistenter Storage
- Context Management

### Multi-Agent Orchestration
- Supervisor-Patterns
- Sub-Agent-Delegation
- Workflows

### Deployments
- Next.js Integration
- Cloudflare Workers
- Netlify Functions

## Featured Beispiele

- **WhatsApp Order Agent** — Restaurant-Bestellungen via WhatsApp
- **YouTube to Blog Agent** — Video-Transkript zu Blog-Post
- **Voice Agent** — TTS/STT mit OpenAI und ElevenLabs
