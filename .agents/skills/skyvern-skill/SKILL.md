# Skyvern

Automates browser-based workflows using LLMs and computer vision — replaces brittle Selenium/Playwright scripts with adaptive AI-driven automation.

## Features
- Visual element detection via computer vision
- LLM-driven decision making
- No code changes when UI changes
- REST API + Python SDK

## Quick Start
```bash
pip install skyvern
skyvern run
```
