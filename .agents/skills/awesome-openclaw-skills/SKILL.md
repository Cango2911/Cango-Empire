# Awesome OpenClaw Skills

## Was ist OpenClaw?

OpenClaw ist ein lokal laufender AI-Assistent. Skills erweitern seine Fähigkeiten — sie erlauben Interaktion mit externen Diensten, Workflow-Automatisierung und spezialisierte Aufgaben.

**Quellen**: Gefiltert aus ClawHub (OpenClaw's öffentlichem Skills-Registry mit 13.729 Skills). Diese Liste enthält 5.400+ kuratierte Skills nach Filterung von Spam, Duplikaten und Malware.

## Installation

```bash
# Via ClawHub CLI
clawhub install <skill-slug>

# Manuell
cp -r <skill-ordner> ~/.openclaw/skills/    # Global
cp -r <skill-ordner> <projekt>/skills/      # Workspace
```

Priorität: Workspace > Local > Bundled
